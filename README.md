# 넷플릭스 비영어권 TV 콘텐츠 수명 분석

넷플릭스 글로벌 **주간 Top 10**(비영어권 TV) 274주 데이터를 시계열로 분석해, 히트작이 얼마나 오래 시청을 유지하는지(콘텐츠 수명)와 그 구조를 살펴본 프로젝트입니다.
분석 결과의 해석과 인사이트는 [REPORT.md](REPORT.md), 이 문서는 데이터·구조·실행 방법을 설명합니다.

### 주요 결과 요약
- **기본 수요**: 완전 연도 4개(2022년에서 2025년)의 주간 시청 시간 중앙값은 166.2M에서 197.2M 사이로, 뚜렷한 성장이나 하락 없이 유지됐습니다. 큰 변동은 소수 대형 신작의 공개 주에 몰려 있습니다.
- **작품 수명**: 롱런작(8주 이상)은 전체 작품의 8.9%지만 전체 시청의 42.7%를 차지합니다. 작품의 77.6%는 4주 이하로 Top 10을 떠납니다.
- **감쇄 패턴**: 비교한 세 대형 작품은 최고점 1주 뒤 61%에서 72%로 떨어졌고, 50% 아래로 내려간 것은 2주에서 3주 뒤였습니다.
- **언어권**: 상위 40개 작품에서 한국어 비중(64.1%)이 높고 최근 더 올랐지만, 오징어 게임을 뺀 한국어의 절대 시청 시간은 늘지 않았습니다. 비중 상승에는 스페인어 작품의 감소도 함께 작용한 것으로 보입니다.

### 데이터 해석 시 주의
- **Top 10 기준입니다.** `시청 시간`은 Top 10에 든 작품의 합계이며 넷플릭스 전체 시청량이 아닙니다.
- 분석에는 `weekly_hours_viewed`(시청 시간)만 썼고 이 컬럼은 비어 있는 값이 없습니다. `runtime`과 `weekly_views`(시청 횟수)는 2023-06-18 주부터만 값이 있어(앞 102주는 전부 비어 있음) 전 기간 비교가 안 되어 쓰지 않았습니다.
- **작품별 시계열에서 Top 10 밖인 주는 0이 아니라 '값 없음(NaN)'** 으로 처리했습니다.
- 작품이 처음 Top 10에 든 **첫 주는 부분 주**일 수 있습니다.
- 작품 수는 title 단위 666편, season 단위 802개입니다. 집계 단위를 구분해서 썼습니다.
- **언어는 원본 컬럼이 아닙니다.** 누적 시청 상위 40편(전체 시청의 40.6%)만 직접 확인해 분류했고 나머지는 '미분류'입니다. 상위 40편의 언어는 제작 국가와 원어를 검색해 확인했습니다(한국어 23편, 스페인어 13편, 일본어·프랑스어·독일어·줄루어 각 1편). 줄루어 중심인 남아공 드라마 「아내가 여럿인 남자 (The Polygamist)」는 '기타(줄루어)'로 분류했고, 멕시코 드라마 「대리모 (The Surrogacy)」는 스페인어로 분류했습니다.
- 달력 연도로 나누면 연말에 시작한 히트작(예: 오징어 게임 시즌 2, 2024-12-29 주)이 두 해로 갈라집니다.
- 이상치(IQR 울타리 기준 22/274주)는 실제 히트 주간이라 **제거하지 않았습니다.**
- 이 데이터는 2021년 중반부터의 집계입니다. 넷플릭스 서비스 전체 역사나 2016~2020년과는 비교하지 못했습니다.

> 원본 데이터의 재배포 조건이 불분명하여(Netflix 이용 약관 1.8조는 서비스에서 얻은 정보의 복제·배포를 제한함), 원본 TSV는 저장소에 포함하지 않습니다. 위 출처에서 직접 내려받아 `data/raw/` 에 넣어 주세요. 이 저장소는 비상업적 학습 목적입니다.

## 3. 분석 방법

- **이동평균**: 4주, 12주 **후행(trailing)** 이동평균입니다. 해당 주와 그 이전 N주만 쓰며 미래 값은 쓰지 않습니다.
- **주간 증감률(WoW)**: 전주 대비 %. 그래프에서는 극단값을 표시용으로 잘라(상한 85%) 보여 주고, 잘린 주는 표로 따로 적었습니다.
- **수명 그룹**: 단기(4주 이하) 77.6% / 중기(5~7주) 13.5% / 롱런(8주 이상) 8.9% (title 단위).
- **반감기**: 작품의 정점(최고 주간 시청 시간)을 100%로 놓고, 유지율이 처음 50% 미만이 된 경과 주차. 정점이 속한 시즌만 사용합니다.
- **계절성**: STL 분해(주기 52주, robust)와 연도별 상관으로 확인했고, 안정적인 연간 계절성은 확인되지 않았습니다.
- **예측**: 롤링 오리진 백테스트로 단순 기준 모델과 MAE를 비교했습니다.
- 멱법칙(power-law) 같은 분포 가정은 검정하지 않았으므로 주장하지 않습니다.

## 4. 실행 방법

테스트한 환경: Windows, Python 3.14.0.

```powershell
git clone https://github.com/love4xox/netflix-content-lifecycle.git
cd netflix-content-lifecycle

py -m venv .venv
.\.venv\Scripts\Activate.ps1      # 실행이 막히면: Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
pip install -r requirements.txt
```

**원본 데이터 내려받기** (노트북 재현처럼 원본이 필요한 작업에 쓰며, 저장소에는 원본이 없습니다)
1. 브라우저에서 넷플릭스 Top 10 페이지(https://www.netflix.com/tudum/top10)에 접속합니다.
2. Downloads → Lists → Global Lists로 이동합니다.
3. `all-weeks-global.tsv`를 내려받습니다.
4. 이 파일을 프로젝트의 `data/raw/` 폴더에 넣습니다. (폴더가 없으면 만듭니다.)

> 실행 전 확인: 터미널 줄 앞에 `(.venv)`가 붙어 있고 경로 끝이 `netflix-content-lifecycle>`인지 봅니다. 터미널을 새로 열면 둘 다 초기화되므로 다시 `.\.venv\Scripts\Activate.ps1`을 실행합니다.

**대시보드**
```powershell
python -m streamlit run app.py
```
브라우저에서 `http://localhost:8501`이 열립니다. 한글 그래프 폰트로 `Malgun Gothic`을 쓰므로 Windows에서 가장 잘 보입니다.

**분석 재현**: `notebooks/`의 노트북을 번호 순서대로 실행하면 `data/interim`, `data/processed`, `images`가 다시 만들어집니다 (01 → 02 → 03 → 04 순서, 위 폴더 구조 참고).

**숫자 확인**
```powershell
python verify_numbers.py
```

## 6. 분석 결정 기록

| 결정 | 선택 | 버린 선택지 | 이유 |
|---|---|---|---|
| 이상치(IQR 울타리 22/274주) | 표시만 하고 값은 유지 | 제거, 상한 처리 | 실제 히트 주간이라 지우면 히트 구조가 사라짐 (이상치 22주 중 오징어 게임이 10주) |
| 이동평균 | 후행 4·12주 (`center` 미사용) | 중심 이동평균 | 미래 값을 쓰지 않음. 대신 정점이 약 (N−1)/2주 늦게 보이는 점을 감안 |
| Top 10 밖인 주 | 값 없음(NaN) | 0으로 채움 | 0으로 두면 유지율이 실제보다 급락한 것처럼 계산됨 |
| WoW 그래프 | 표시용으로 상한 85% 클리핑, 잘린 주는 표로 별도 기재 | 클리핑 없이 표시 | 극단값 몇 개가 축을 지배해 나머지 변동이 안 보임 |
| 작품 집계 단위 | 작품(title) 단위 요약, 반감기는 정점이 속한 시즌만 | 시즌 단위 전체 | 시즌을 섞으면 정점·유지율 기준이 흔들림 |
| 언어 분류 | 상위 40편 직접 분류(커버리지 40.6%) | 제목 키워드 자동 분류 | 키워드 방식은 오분류가 생김 (예: 'Dark Desire'를 '다크'로 오인) |
| 계절성 판단 | STL(주기 52, robust) + 상한 처리 후 연도별 상관 | STL 한 번으로 결론 | 메가히트가 계절 성분을 오염시킬 수 있고 주기가 약 5번뿐이라, 안정적인 연간 계절성은 없다고 판단 |

## 8. 한계

- Top 10 안의 시청 시간만 있어 전체 시청량, 구독자 수, 신작 공개 일정은 알 수 없습니다.
- 언어는 상위 40편만 직접 분류했습니다. 한국어 비중이 높은 것이 실제 증가인지 분모 효과인지는 추가 분석이 필요합니다.
- 1위 작품과 주간 급등 시점이 겹쳐도 원인으로 단정하지 않았습니다.
